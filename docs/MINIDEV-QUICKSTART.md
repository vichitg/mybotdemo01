## สถาปัตยกรรมที่แก้แล้ว
BotTeam ใช้ Docker project `botteam` ใน Ubuntu-24.04 ที่ `/root/botteam-rakazo` แยกจาก BotPress เดิมที่พอร์ต 5173/3110
ข้อมูลบัญชีแอปอยู่ใน `%LOCALAPPDATA%\BotTeamMiniDev\owner.json` ไม่ใช้ owner ของ BotPress ร่วมกัน
`router-bridge.mjs` ผูกเฉพาะ IP ของ WSL adapter พอร์ต 20129 และส่งต่อเฉพาะ API ไป Windows loopback ของ 9Router ไม่เปิด Dashboard บน bridge
`botteam.local.json` เก็บ URL/Model ของเครื่อง; คีย์ยังอยู่ใน `9router-api-key.txt`; ทั้งสองไม่ถูกติดตามโดย Git
แก้การ login ซ้ำเมื่อเชื่อมโมเดลพลาด และพักคำขอเมื่อได้รับ 429; ไม่ปิดหรือแก้โปรเจกต์ BotPress

## ขอบเขตที่ยังไม่รับรอง
ผลนี้ยืนยัน Kimi ผ่าน 9Router ไม่ใช่การยืนยันสิทธิ์ ChatGPT Subscription; provider อื่นต้องตรวจสิทธิ์/โควตาและทดสอบแยก
ยังไม่ได้ทดสอบ computer-use พร้อมกันทั้ง 9 ตัว เสียงพูด การอนุมัติทุกรูปแบบ และชุด regression เดิมทั้งหมด ห้ามใช้ข้อมูลลูกค้าจริง
